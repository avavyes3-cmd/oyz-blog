# 🌸 oyz_blog

个人笔记博客，基于 Sakura 主题构建。

**技术栈**: HTML + CSS + JS 纯静态，SPA 架构，Vercel 部署。

**特性**: 
- 🌸 Sakura 日系主题样式
- 🤖 Live2D 碧蓝航线大凤背景
- 📝 Markdown 文章上传
- 🔍 lunr.js 全文搜索
- 🎵 APlayer 本地音乐播放
- 📊 访问量统计
- 💻 TI 竞赛 2024-H 代码逐行注释（103 源文件）
- 📱 移动端响应式适配

**部署**: `https://oyz-blog.vercel.app` | `https://avavyes3-cmd.github.io/oyz-blog/`
